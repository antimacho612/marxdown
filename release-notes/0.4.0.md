title: Front matter at a glance, links in new tabs
---

## What's new

- **Front matter reads as a table.** YAML front matter at the top of a document is now shown as a key–value table in the preview. Switch back to highlighted YAML, or hide it, with `preview.frontMatter`.
- **Links open in a new tab.** Following a link to another Markdown file in the preview now opens it in a new tab, so the document you came from stays open. If the file is already open, Marxdown switches to its tab.
- **Choose where pasted images go.** Set `editor.pasteImage.directory` to a path relative to the document. The default is still `<file name>.assets`.
- **Bold and italic stand out in the editor.** `**bold**` and `*italic*` now have their own colors instead of matching the surrounding text.
- **Inline code is easier to spot.** Its background in the preview no longer blends into the page.
- **Fixes.** Content piped with `<command> | marxdown -` now opens when Marxdown is already running. If the tray icon cannot be created, closing the window with `✕` now quits instead of leaving no way to bring it back.

## Why it matters

Design documents and AI-generated notes often start with front matter and point to other files.
This release makes that metadata readable at a glance and lets you follow links without losing your place.
